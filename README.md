# Python Trivia Quiz 🎯

A beginner-friendly command-line trivia quiz built using Python and the Open Trivia Database API.

## About the Project

This project is a simple multiple-choice quiz that fetches questions from the Open Trivia Database API.

The quiz asks 10 easy Computer Science questions and allows the user to select an answer from four options. At the end, the user's score is displayed.

## Features

- Fetches quiz questions using an API
- 10 easy Computer Science questions
- Multiple-choice questions
- Randomizes the answer options
- Validates user input
- Keeps track of the score
- Displays the final score
- Handles connection errors

## Technologies Used

- Python
- Requests
- Open Trivia Database API
